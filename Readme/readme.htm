Quick Start

You must first install the game to your hard drive. Use the Installation interface or browse your computer for the Test Drive 6 CD, and double-click it. Once installed, you can launch Slave by clicking Start-->Programs-->Test Drive 6-->Test Drive 6. If the installation interface doesn't open when you put the disk in, Double click on "My Computer" and double click on the CD-ROM Drive, this should open the installation interface.

System Requirements

  • Windows 95/98
  • Pentium 233
  • 32 Mb RAM
  • DirectX 7.0 (included on CD and must be installed)
  • 4Mb Direct 3D compatible 3d accelerator card
  • DirectX 7 compatible sound card (with up-to-date drivers)
  • 4X CD Drive
  • 250 MB Hard Drive Space
  • Keyboard or Analog/Digital Controller
